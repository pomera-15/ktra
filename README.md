# ktra (カトレア) - Personal AI Agent

[OpenAI Agent SDK](https://github.com/openai/openai-agents-python)を使用したパーソナルAIエージェントです。日常のタスク管理、実行支援、情報整理を行います。

## 🚀 機能

- **タスク管理**: 自然言語でのタスク登録・更新・一覧表示
- **コマンド実行**: 安全なシェルコマンドの実行
- **状況要約**: タスクの進捗状況を要約
- **対話式CLI**: 自然言語での操作
- **高機能インターフェース**: 
  - 🎨 美しい色分けとアイコン表示
  - 📝 コマンド履歴とオートコンプリート
  - ❓ 対話的ヘルプシステム
  - ⚡ プログレスバーと視覚的フィードバック

## 📋 主な機能

### タスク管理
- `明日までに資料作成` → 構造化してタスク登録
- `今日やることは？` → タスク一覧表示（優先度順）
- `資料作成タスク終わった` → タスク完了更新

### コマンド実行
- `ls`, `git status`, `pwd` などの安全なコマンド実行
- システム情報の取得

## 🛠 セットアップ

1. **依存関係のインストール**
```bash
pip install -r requirements.txt
```

2. **環境変数の設定**
```bash
cp .env.example .env
# .envファイルにOpenAI API キーを設定
OPENAI_API_KEY=your_openai_api_key_here
```

3. **実行**
```bash
python main.py
```

## 🔒 セキュリティ

- 危険なコマンド（`rm -rf`, `sudo`など）の実行を制限
- 許可されたコマンドのみ実行可能
- コマンド実行のタイムアウト制限（30秒）
