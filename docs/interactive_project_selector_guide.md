# インタラクティブプロジェクトセレクター 使用ガイド

## 概要

ktraの対話中に `/projects` と入力すると、インタラクティブなプロジェクト管理画面が表示されます。矢印キーでプロジェクトを選択し、直感的に操作できます。

## 起動方法

```
ktra> /projects
```

## 画面構成

```
📁 プロジェクト一覧 (active) - 矢印キーで選択, Enterで操作

→ 🚀 Webサイト開発 (3タスク)
   新しいWebサイトの開発プロジェクト
   📅 06/30 | 🏷️ Web, 開発 | 📁 フォルダあり

  📋 モバイルアプリ (1タスク)
  ✅ ドキュメント整理 (0タスク)
  ⏸️ 研究プロジェクト (2タスク)

操作: ↑↓ 選択  Enter 操作メニュー  n 新規作成  f フィルター  o フォルダ開く  r 更新  h ヘルプ  q 終了
```

## キーボード操作

### 基本操作
- **↑/↓**: プロジェクトの選択
- **Enter**: 選択したプロジェクトの操作メニューを開く
- **q**: セレクターを終了

### クイックアクション
- **n**: 新しいプロジェクトを作成（直接入力）
- **f**: フィルター変更
- **o**: 選択中のプロジェクトフォルダを開く
- **r**: プロジェクトリストを更新
- **h**: ヘルプ表示

## 操作メニュー

プロジェクトを選択してEnterを押すと、以下の操作メニューが表示されます：

### 1. ステータス変更
- 📋 計画中
- 🚀 アクティブ
- ⏸️ 保留中
- ✅ 完了
- 📦 アーカイブ

### 2. 詳細を編集
プロジェクト名、説明、タグを編集できます。

### 3. フォルダを開く
プロジェクトフォルダをFinderで開きます。

### 4. メモを作成
プロジェクト内にメモファイルを作成します。

### 5. ファイル一覧
プロジェクトフォルダ内のファイル一覧を表示します。

### 6. 削除
確認後、プロジェクトを削除します。

## フィルター機能

**f**キーでフィルターを変更できます：

- **すべて**: 全プロジェクトを表示
- **アクティブ**: アクティブなプロジェクトのみ
- **計画中**: 計画中のプロジェクトのみ
- **保留中**: 保留中のプロジェクトのみ
- **完了済み**: 完了したプロジェクトのみ

## 表示情報

### アイコンの意味

**ステータス**:
- 📋 計画中
- 🚀 アクティブ
- ⏸️ 保留中
- ✅ 完了
- 📦 アーカイブ

### 詳細情報（選択中のみ表示）
- 📄 説明
- 📅 期限
- 🏷️ タグ
- 📁 フォルダの有無
- タスク数

## プロジェクト作成機能

### 直接作成
- **n**キーを押すと、プロジェクト作成画面に移行
- プロジェクト名（必須）
- 説明（オプション）
- タグ（オプション、カンマ区切り）
- 自動でフォルダ構造を作成

### フォルダ構造
```
project_files/
  プロジェクト名_プロジェクトID/
    README.md          # プロジェクト概要
    notes/            # メモ類
    documents/        # ドキュメント
    references/       # 参考資料
```

## 使用例

### 1. 日常のプロジェクト確認
```
ktra> /projects
↑↓で確認したいプロジェクトを選択
Enter → 「ファイル一覧」→ 進捗確認
```

### 2. プロジェクトのステータス更新
```
ktra> /projects
↑↓で完了したプロジェクトを選択
Enter → 「ステータス変更」→ 「完了」
```

### 3. 新しいプロジェクトの作成
```
ktra> /projects
n → プロジェクト情報を直接入力
```

### 4. プロジェクトメモの作成
```
ktra> /projects
↑↓でプロジェクトを選択
Enter → 「メモを作成」→ タイトルと内容を入力
```

### 5. プロジェクトフォルダの確認
```
ktra> /projects
↑↓でプロジェクトを選択
o → Finderでフォルダを開く
```

## 特徴

- **直感的操作**: 矢印キーとEnterだけの簡単操作
- **リアルタイム更新**: 変更は即座に保存・反映
- **フォルダ統合**: プロジェクトフォルダの直接操作
- **視覚的分かりやすさ**: アイコンとカラーでの情報表示
- **フィルタリング**: 状況に応じた表示の絞り込み
- **タスク連携**: 関連タスク数の表示

## プロジェクトとタスクの連携

- タスク作成時にプロジェクトを選択可能
- プロジェクト詳細でタスク数を確認
- プロジェクト内のメモやドキュメントをAIが参照
- プロジェクト単位でのタスク整理と管理
