# インタラクティブタスクセレクター 使用ガイド

## 概要

ktraの対話中に `/tasks` と入力すると、インタラクティブなタスク選択画面が表示されます。矢印キーでタスクを選択し、直感的に操作できます。

## 起動方法

```
ktra> /tasks
```

## 画面構成

```
📝 タスク一覧 (active) - 矢印キーで選択, Enterで操作

→ 🔄 🟡 🔋 新機能の実装
   📄 APIの新機能を追加する
   ⏱️ 120分 | 📁 ktra開発 | 📅 06/25

  ✅ 🔴 ⚡ テストの修正
  📥 🟡 🔋 ドキュメント更新
  🚫 🟠 🪫 レビュー対応

操作: ↑↓ 選択  Enter 操作メニュー  n 新規作成  f フィルター  r 更新  h ヘルプ  q 終了
```

## キーボード操作

### 基本操作
- **↑/↓**: タスクの選択
- **Enter**: 選択したタスクの操作メニューを開く
- **q**: セレクターを終了

### クイックアクション
- **n**: 新しいタスクを作成（直接入力、AI相談なし）
- **f**: フィルター変更
- **r**: タスクリストを更新
- **h**: ヘルプ表示

## 操作メニュー

タスクを選択してEnterを押すと、以下の操作メニューが表示されます：

### 1. ステータス変更
- 📥 受信箱
- ⏭️ 次のアクション
- 🔄 実行中
- 🚫 ブロック中
- ✅ 完了
- 📦 アーカイブ

### 2. 詳細を編集
AIエージェントが対話的にタスクの編集を支援します。

### 3. AIに相談
タスクに関する以下の相談ができます：
- このタスクの進め方を相談
- 必要なリソースを教えて
- 時間見積もりの妥当性をチェック
- 類似タスクとの比較
- カスタム質問

### 4. 削除
確認後、タスクを削除します。

## フィルター機能

**f**キーでフィルターを変更できます：

- **すべて**: 全タスクを表示
- **アクティブ**: 未完了タスクのみ
- **完了済み**: 完了したタスクのみ
- **実行中**: 現在作業中のタスクのみ
- **ブロック中**: ブロックされたタスクのみ

## 表示情報

### アイコンの意味

**ステータス**:
- 📥 受信箱
- ⏭️ 次のアクション
- 🔄 実行中
- 🚫 ブロック中
- ✅ 完了
- 📦 アーカイブ

**優先度**:
- 🔴 緊急・重要
- 🟡 重要・非緊急
- 🟠 緊急・非重要
- 🟢 非緊急・非重要

**エネルギーレベル**:
- ⚡ 高エネルギー
- 🔋 中エネルギー
- 🪫 低エネルギー

### 詳細情報（選択中のみ表示）
- 📄 説明
- ⏱️ 推定時間
- 📁 プロジェクト
- 📅 期限
- 🏷️ タグ

## AI統合

タスクセレクターからのAI支援は、元のktra対話に戻って継続されます：

1. タスク選択 → 操作メニュー → AIに相談
2. 相談内容を選択
3. ktraメイン画面でAIが回答
4. 必要に応じて追加の対話が可能

## 使用例

### 1. 日常のタスク確認
```
ktra> /tasks
↑↓で確認したいタスクを選択
Enter → 「AIに相談」→ 「このタスクの進め方を相談」
```

### 2. タスクのステータス更新
```
ktra> /tasks
↑↓で完了したタスクを選択
Enter → 「ステータス変更」→ 「完了」
実際にかかった時間を入力
```

### 3. 新しいタスクの作成
```
ktra> /tasks
n → タスクタイトルを直接入力して作成
```

## 特徴

- **直感的操作**: 矢印キーとEnterだけの簡単操作
- **リアルタイム更新**: 変更は即座に保存・反映
- **AI統合**: タスク操作とAI支援のシームレスな連携
- **視覚的分かりやすさ**: アイコンとカラーでの情報表示
- **フィルタリング**: 状況に応じた表示の絞り込み
