# タスクモード使用ガイド

## 概要

ktraの対話中に `/tasks` と入力すると、専用のタスク管理モードに移行できます。このモードでは、タスクのCRUD操作を効率的に実行できます。

## 起動方法

```
ktra> /tasks
```

## 利用可能なコマンド

### 基本操作

- `list` / `ls` - タスク一覧を表示
- `create` / `new` - 新しいタスクを作成
- `show <id>` - タスク詳細を表示
- `update <id>` - タスクを更新
- `delete <id>` - タスクを削除

### 検索・フィルター

- `search <キーワード>` - タスクを検索
- `filter` - フィルター表示
- `stats` - 統計情報

### その他

- `help` - ヘルプを表示
- `exit` / `quit` - タスクモードを終了

## 使用例

### 1. タスクの作成
```
tasks> create
タスクのタイトル: 新機能の実装
説明（オプション）: APIの追加機能を実装する
...
```

### 2. タスク一覧の表示
```
tasks> list
```

### 3. ステータス別表示
```
tasks> list in_progress
```

### 4. タスクの検索
```
tasks> search 実装
```

### 5. タスクの更新
```
tasks> update "新機能の実装"
```

### 6. 統計情報
```
tasks> stats
```

## 特徴

- **Rich UI**: カラフルで見やすいテーブル表示
- **対話的操作**: ステップバイステップでの入力支援
- **柔軟な検索**: IDまたはタイトルでの検索
- **フィルタリング**: ステータス、優先度、プロジェクト別表示
- **統計機能**: 生産性の可視化

## 注意事項

- タスクIDの代わりにタスクタイトルの一部も使用できます
- Ctrl+C で緊急時にモードを終了できます
- 変更は即座に保存されます
